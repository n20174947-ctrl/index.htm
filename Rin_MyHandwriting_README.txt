Rin My Handwriting Prototype — version 1.0

Includes an installable TTF with custom vector-drawn glyphs for Russian Cyrillic, Ukrainian-specific letters,
digits 0–9 and common punctuation. This is a custom handwritten-inspired prototype based on the notebook photos,
not a pixel-perfect tracing of every photographed glyph. Some glyphs and joins may need revision.
Use the included CSS snippet to load it on GitHub Pages.
